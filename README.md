# Walmart Sales Analysis - End-to-End Data Project

## Overview
This project analyzes 10,000+ Walmart transaction records to answer real
business questions around revenue, profitability, customer payment behavior,
and branch performance. It covers the full pipeline: cleaning raw data in
Python, loading it into PostgreSQL, writing SQL to answer business questions,
and visualizing the results in an interactive dashboard.

## Project Structure
```
walmart_project/
├── data/
│   ├── Walmart.csv              # raw data
│   └── walmart_clean_data.csv   # cleaned data (generated by clean_data.py)
├── scripts/
│   ├── clean_data.py            # cleaning + feature engineering
│   ├── load_to_db.py            # loads clean data into PostgreSQL (optional)
│   └── run_queries_duckdb.py    # runs all 12 SQL queries directly on the CSV (no DB server needed)
├── sql/
│   ├── business_queries.sql     # SQL answers to 12 business questions (Postgres syntax)
│   └── query_results.md         # actual output of every query (generated)
├── dashboard/
│   └── app.py                   # Streamlit interactive dashboard
├── requirements.txt
└── README.md
```

## How to Run

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Clean the data**
   ```bash
   python scripts/clean_data.py
   ```

3. **Run the business-question SQL (no database install needed)**
   ```bash
   python scripts/run_queries_duckdb.py
   ```
   This runs all 12 queries directly against the cleaned CSV using DuckDB
   and saves the full output to `sql/query_results.md`.

   **Alternative:** if you'd rather use a real PostgreSQL server (closer to
   a production setup), create a database called `walmart_db`, update the
   credentials in `scripts/load_to_db.py`, run it, then run the same queries
   from `sql/business_queries.sql` in any SQL client.

4. **Launch the dashboard**
   ```bash
   streamlit run dashboard/app.py
   ```

## Business Questions Answered
1. Which payment methods are most used, and how much volume do they carry?
2. Which product category is rated highest in each branch?
3. What is the busiest day of the week per branch?
4. How does sales quantity break down by payment method?
5. How do category ratings vary by city?
6. Which category generates the most total profit?
7. What's the most common payment method per branch?
8. How are transactions distributed across Morning/Afternoon/Evening shifts?
9. Which branches saw the sharpest revenue decline year-over-year?
10. **(Extended)** Which category is most profitable *per unit sold*, not just in total? *(This surfaces a different answer than Q6 - see Findings below.)*
11. **(Extended)** Which cities generate the most total revenue?
12. **(Extended)** Does customer satisfaction (rating) correlate with how much they buy?

## Key Findings

- **Payment behavior:** Credit card is the most-used payment method (4,256
  transactions, ~9,567 units sold), followed by Ewallet (3,881 transactions)
  and Cash (1,832 transactions) — cash is a distant third across the board.

- **Total profit vs. profit efficiency (the key insight):** Fashion
  Accessories and Home & Lifestyle generate the most total profit
  (~$192K each) simply because of volume (9,600+ units sold). But on a
  **profit-per-unit basis**, Food & Beverages is actually the most efficient
  category ($22.64/unit) despite ranking near the bottom on total profit
  ($21.5K). This means: total-profit rankings alone would lead Walmart to
  over-invest in Fashion/Home categories, when Food & Beverages is quietly
  the highest-margin category per item sold.

- **Revenue concentration:** The top 2 cities (Weslaco, Waxahachie) generate
  roughly 2x the revenue of the next 3 cities combined — revenue is not
  evenly distributed across locations, suggesting regional demand
  differences worth investigating further (local demographics, competition,
  store size).

- **Branch decline risk (corrected for sample size):** The initial query
  flagged branches with 90%+ revenue "decline," but closer inspection showed
  these branches had only 1-2 transactions per year — not a real trend, just
  noise from a tiny sample. After filtering to branches with at least 5
  transactions per year, the real decline leaders are **WALM054 (-51%)**,
  **WALM025 (-50%)**, and **WALM074 (-30%)** — meaningful, defensible drops
  worth investigating (local competition, staffing, inventory issues).

- **Shift patterns:** Afternoon is consistently the busiest shift across
  branches, with Morning the quietest — relevant for staffing schedules.

### Recommendation
Walmart should not rely on total-profit rankings alone when deciding where
to focus marketing or shelf space. A dual view — total profit *and*
profit-per-unit — surfaces Food & Beverages as an under-recognized,
high-margin category worth expanding. On branch performance, the raw
year-over-year revenue-decline query initially surfaced misleading results
driven by branches with almost no transactions in a given year; after
applying a minimum transaction-volume filter, WALM054, WALM025, and WALM074
emerge as branches with genuine, meaningful revenue declines worth a
targeted investigation before the next planning cycle.

*(Full query outputs are saved in `sql/query_results.md` after running
`scripts/run_queries_duckdb.py`.)*
